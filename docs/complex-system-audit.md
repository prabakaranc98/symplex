# Symplex: independent complex-system cycle audit

Reviewed 2026-09-10. This is an implementation audit and requirements stress test, not a scientific result for any example domain. No paid model calls were made for the audit or its regression tests. The review used the evaluation, verification, context-engineering and harness-engineering skills, local runtime code, and the primary references linked below.

Symplex should organize the agent's work around an evolving decision and a falsifiable representation of its system. Multimodal perception, hybrid modeling and additional compute are useful when they resolve a specific uncertainty. They are not interchangeable: an image is an observation format, a neural model is a computational component, a symbolic rule is a constraint or claim, and a stochastic simulator describes a proposed mechanism under specified assumptions. Combining them requires explicit interfaces and evidence about those interfaces.

## Findings from the initial runtime

1. **New context can fail to change the investigation.** In the initial `agents/solver.py`, completed-job identity excluded user steering, and Problem DNA was generated from problem text without attached context. Binary inputs were absent from the planner's context inventory. A new judgment after a completed investigation could return the old job. Framing, job identity and the next-action context need a common, versioned input snapshot. Adding or replacing evidence should state which hypotheses, models and conclusions require reassessment.

2. **The checker could not inspect the numerical work.** `review_model` received the latest blueprint, without actual generated code, results, diagnostics, evidence or steering. Its critique therefore could challenge the plan but could not validate an executed comparison. The reviewer should receive a frozen evaluation contract and the selected artifacts, identify exact failing checks, and abstain on inaccessible evidence. Distinct roles or model names alone do not establish independent scientific validation; LLM judges can exhibit position, verbosity and self-preference biases. Host-recomputed checks and an appropriate held-out or external experiment remain separate evidence. [Zheng et al., LLM-as-a-Judge](https://arxiv.org/abs/2306.05685)

3. **A computation revision lacked the program it was revising.** The initial hosted-compute path sent user attachments and bounded summaries, but did not supply previously generated code/CSV/JSON. Its cache identity excluded prior compute outputs. This audit implements an explicit `predecessor_package_id`: a revision uploads capped predecessor files only to the hosted sandbox and binds its identity to their hashes. Default retries remain idempotent and do not automatically select the output they just created. Missing, stale, foreign or corrupted references fail before upload; traces identify actual supplied sources. This repairs transport and lineage, not empirical validity.

4. **Scientific properties were mostly prose.** Blueprint ports, units, clocks, uncertainty and hypothesis tests were free text; RDF serialized proposed relationships but did not check them. Introduce typed quantities, observation operators, evidence references, competing-hypothesis groups, parameter provenance, coupling transformations and executable acceptance checks. A dimensionally compatible coupling still needs a justified scientific interpretation. FMI is useful inspiration for exchanging heterogeneous dynamic model components; importing an FMU alone would not validate the coupled system. [FMI standard](https://fmi-standard.org/)

5. **Generic computation had no independent scoring gate.** A completed Python tool call and generated plot were sufficient for an exploratory package. Agent-authored diagnostic assertions could be saved but were not independently recomputed. Preserve the exploratory label and introduce a separate experiment protocol, result schema and verification artifact. Track numerical verification, empirical comparison, calibration and decision relevance as different outcomes. COMBINE distinguishes biological model formats, simulation-experiment descriptions and packaging; this separation should also guide Symplex's generic artifact contracts. [COMBINE standards](https://co.mbine.org/standards/)

6. **More steps did not yet mean principled improvement.** Depth profiles changed reasoning effort and action counts, while some repeated-tool proposals immediately forced delivery. Keep per-tool limits, but return bounded rejection feedback so the planner can select a different useful action. Allocate further tests to unresolved decision-relevant differences, numerical instability, evidence conflicts and failure localization. The generic system needs a candidate archive and comparable experiment records before its repeated runs can count as algorithmic improvement.

The provider's text-byte reservation plus a fixed allowance is also not a proved upper bound on every multimodal or tool-output token stream. Preserve actual usage reconciliation and report any unresolved reservation overrun explicitly. The workspace's bounded budget should not be described as unlimited test-time compute.

## Required reasoning and execution contracts

The agent team should share versioned artifacts while receiving different context and permissions:

- **Framer and perception agent:** establish beneficiary, decision authority, alternatives, value judgments, success criteria, constraints, spatial and temporal boundaries, observations, intervention options and missing input. Preserve the original modality and attach extraction uncertainty; OCR, a caption or a PDF summary is derived evidence. User steering changes the relevant version rather than silently rewriting a past result.
- **System architect:** construct entities, states, flows, mechanisms, observation processes, confounders, exogenous drivers and feedback. Choose the simplest adequate component families, including hybrids when justified. Each port identifies its entity, quantity, dimension, unit, shape, time support, spatial frame, uncertainty representation and source. Each coupling specifies alignment, conversion, aggregation, conservation and error propagation.
- **Hypothesis and evidence agents:** propose plausible rivals, assumptions and observations that discriminate them. Assess falsifiability, identifiability, circularity, duplicated evidence, domain transfer and confounding before spending compute. Record claim-level support and contradiction; a relevant paper or metadata hit is not itself a verified mechanism.
- **Experiment designer and simulation engineer:** freeze a baseline, target estimand, evaluation unit, controls, numerical tolerances, invariant checks, data split, stochastic replication, disconfirmation criterion and output contract. Execute with recorded code, versions, inputs and seeds. A neural surrogate should expose its training support and approximation error where it couples to a mechanistic model. An optimization result is conditional on its objective, constraints and model fidelity.
- **Independent evaluator and metareasoner:** inspect actual results against the frozen contract, localize failures and compare meaningful rivals. Separate stochastic variability, parameter uncertainty, model discrepancy, observation error and ignorance. Revise implicated components or collect discriminating evidence rather than merely asking the same model to sound more certain.
- **Decision and presentation agent:** connect alternatives to supported consequences, trade-offs, uncertainty, distributional effects, reversibility and the next validation. Produce model/source/experiment views from versioned artifacts. A map, molecule viewer, trajectory or forecast interval must retain its basis, units and provenance when the user changes views.

Test-time search should keep diverse candidates across explicit behavior descriptors and measured quality. MAP-Elites provides an archive-based pattern for retaining qualitatively different high-performing candidates; a gallery of agent-written hypotheses is not an implemented MAP-Elites search. Descriptors, replacement rules, feasibility checks, evaluations and compute cost must be recorded. [Mouret and Clune, MAP-Elites](https://arxiv.org/abs/1504.04909)

Method evolution needs a distinct parent method, bounded allowed patch, development evidence, independent validation tasks, protected final assessment, matched compute and a rollback condition. Preserve unsuccessful candidates and negative results. Do not let a candidate rewrite its own metric, held-out split, permission envelope or promotion threshold. Current narrow P1/research pilots do not establish general recursive self-improvement or transfer across scientific domains.

## Requirements stress tests, not solved cases

**Urban infrastructure.** A useful agent may need to couple travel demand, transport networks, accessibility, land use, construction capacity, environmental measurements and human responses across different clocks and spatial resolutions. The system must distinguish an observed map from a proposed development, maintain CRS and population denominators, and compare alternatives against budget and distributional objectives. Required tests include unit/frame alignment, network flow conservation, stochastic-demand replication, baseline reproduction and sensitivity to uncertain behavior. A visually plausible map or normalized influence graph is insufficient evidence that an airport location is feasible.

**Protein design and organismal resilience.** The agent must first distinguish molecular structure, biochemical kinetics, cell response, tissue/organ dynamics and organism-level recovery as different targets. Sequence, structure, assay tables, time series and microscopy require different observation operators and provenance. A proposed molecular representation or simulated trajectory does not establish function, whole-organism resilience or efficacy. A resilience problem needs an explicit perturbation, baseline, timescale and recovery endpoint; coupling across scales requires evidence and sensitivity checks. SBML/CellML model representations and SED-ML experiment packages are relevant extension interfaces, with installed capability verified before execution. [COMBINE standards](https://co.mbine.org/standards/)

**Prediction markets.** Contracts, resolution rules, timestamps, availability cutoffs and dependent events must be part of the semantics. News/text perception cannot replace settlement definitions. Compare forecasts against raw-price and simple reference forecasts on the same eligible event groups; preserve point-in-time availability and avoid treating correlated contracts as independent samples. Keep forecast quality, calibration, decision utility, transaction frictions and any causal interpretation distinct. The existing strict P1 admission and host scoring offer a useful narrow pattern, but do not make arbitrary market, behavioral or financial models validated.

Across all three, the same product cycle should operate while the evidence requirements, model components, simulator adapters and acceptance protocols change. The engine's claim should be that it can frame, construct, execute, inspect and improve scoped investigations with explicit capability gaps. Universal scientific reliability is not established by these software mechanisms or by a successful synthetic demonstration.
